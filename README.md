# PriceCompare

Search for a product and compare its price across local shop branches and web shops.

## Idea

1. You type a product name (fuzzy matching, so the name does not have to be exact).
2. You say where you live.
3. The tool looks up prices in shops with branches near you and in web shops.
4. You get one price comparison breakdown.

## Status

Early stage. Market research is in progress to decide whether an existing free tool already covers
this, or whether it will be built here.
